# Quarto Book Template

to be edited 

A minimal two-chapter [Quarto](https://quarto.org) book template with an
Aalto-branded light/dark theme (colors, typography, sidebar logo), ready to
be filled with new content. It ships pre-populated with lorem-ipsum
placeholder chapters that demonstrate the chapter structure, callout usage,
and image-embedding pattern.

## What's Included

- `book/_quarto.yml` — book configuration
- `book/custom-light.scss` / `book/custom-dark.scss` — Aalto-branded themes
- `book/aalto-logo-black.png` / `book/aalto-logo-white.png` — sidebar logo assets
- `book/index.qmd` — placeholder preface
- `book/ch01-chapter-one.qmd`, `book/ch02-chapter-two.qmd` — placeholder chapters,
  each demonstrating the full authoring pattern (callouts, an embedded image,
  exercises, references) in lorem ipsum text
- `book/CLAUDE.md` — authoring guide describing the chapter template
- `.github/workflows/publish.yml` — GitHub Pages deploy workflow (builds with
  the official `quarto-dev/quarto` Docker image)
- `environment.yml` — minimal conda/mamba spec (Python + Quarto) to recreate
  the local build environment reproducibly, without committing it

## What's NOT Included

This is a content-free scaffold. Before publishing, you should:

- Replace `book/index.qmd`, `book/ch01-chapter-one.qmd`, and
  `book/ch02-chapter-two.qmd` with real content (or add more chapters —
  see `book/CLAUDE.md`)
- Update `title:` and `author:` in `book/_quarto.yml`
- If hosting on GitHub, add `repo-url:` and `repo-actions: [edit, source, issue]`
  back into `book/_quarto.yml`

## Building Locally

`env/` (the local conda/mamba environment) is not committed to git — recreate
it from `environment.yml`:

```bash
mamba env create -p ./env -f environment.yml
```

Then, from the repository root, activate it and render:

```bash
mamba activate ./env
quarto preview book/
quarto render book/     # output: book/_book/index.html
```

(`mamba run -p ./env quarto render book/` works too, without activating.
Don't call `./env/bin/quarto` directly — the conda-forge `quarto` package
needs the environment's activation scripts to locate its bundled pandoc/deno/
esbuild/sass/typst. A system-wide `quarto` install works just as well if you
have one, activation-free.)

## Customizing

To add or reorder chapters, edit the `chapters:` list in `book/_quarto.yml`
and follow the chapter template documented in `book/CLAUDE.md`. To change the
look, edit `book/custom-light.scss` / `book/custom-dark.scss`, or swap the
logo files.

## Build Artifacts

`book/_book/` (rendered output) and `book/.quarto/` (cache) are generated by
`quarto render`/`quarto preview` — safe to delete, and already excluded via
`.gitignore` (along with `env/`, which is recreated from `environment.yml`
rather than committed).
